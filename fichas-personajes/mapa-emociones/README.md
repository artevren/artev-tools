# Mapa de emociones

Herramienta interactiva para representar diez dimensiones emocionales de personajes ficticios.

## Características
- Diez emociones con puntos ajustables de 0 a 100.
- Gráfico radial interactivo.
- Color del gráfico personalizable.
- Descarga del resultado en formato PNG.
- Crédito: @artev.ren
